Linux 入门精简笔记：命令、命令行与目录结构

---

## 一、命令 & 命令行

### 1. 什么是命令

- **命令**：在 Linux 中，让系统执行某个操作的一段“文字指令”  
  - `ls`：查看目录内容  
  - `cd`：切换目录  
  - `mkdir`：创建目录  

**一句话：命令 = 人对系统说的话（让系统做什么）。**

### 2. 什么是命令行

- **命令行**：输入和执行命令的地方  
  - 也叫：终端（Terminal）、Shell、控制台

**类比：**
- 命令：你说的话  
- 命令行：你说话的地方  

---

## 二、Linux 命令的通用格式

```bash
command [-options] [parameter]
```

- **命令本体（command）**：做什么  
  - 如：`ls`、`cd`、`pwd`、`mkdir`
- **选项（options）**：怎么做（控制细节）  
  - 短选项：`-a`  
  - 组合：`-la`  
  - 长选项：`--help`
- **参数（parameter）**：对谁做（操作对象）  
  - 如：文件名、目录名、路径、用户名……

### 常见组合示例

- **只有命令本体**

  ```bash
  pwd              # 查看当前所在目录
  ```

- **命令 + 选项**

  ```bash
  ls -a            # 显示包括隐藏文件在内的所有文件
  ls -l            # 以详细格式显示
  ls -la           # 详细 + 显示隐藏文件
  ```

- **命令 + 参数**

  ```bash
  cd /home         # 切换到 /home 目录
  mkdir test       # 创建名为 test 的目录
  ```

- **命令 + 选项 + 参数**

  ```bash
  ls -l /home      # 以详细格式查看 /home 目录内容
  ```

### 容易混淆的点

- **命令不是中文句子**
  - 错：`查看文件`
  - 对：`ls`
- **命令 ≠ 命令行**
  - 命令：`ls`、`cd`、`mkdir`
  - 命令行：输入这些命令的界面
- **选项 vs 参数**
  - 选项：控制“怎么做”（如 `-l`）
  - 参数：控制“对谁做”（如 `/home`）

### 本节小结（背诵版）

1. 命令是用户输入给系统的**文字指令**。  
2. 命令行是输入和执行命令的**字符界面**。  
3. 通用格式：**命令本体 + 选项 + 参数**。  
4. 本体 = 做什么，选项 = 怎么做，参数 = 对谁做。

## 三、Linux 目录结构概念

### 1. 树状结构 & 根目录 `/`

- Linux 文件系统是**树状结构**：  
  - **只有一个顶级目录**：根目录 `/`
- Windows 有多个盘符：`C:\`、`D:\`、`E:\`……

**例子：**

- Linux：`/home/alice/test.txt`  
  - 从 `/` → `home` → `alice` → `test.txt`
- Windows：`C:\Users\Alice\test.txt`

**一句话：所有文件，最终都挂在 `/` 这棵树上。**

---

## 四、常见目录的作用（只记最关键）

- **`/bin`**：系统**常用命令**  
  - 如：`ls`、`cp`、`mv`、`rm`

- **`/boot`**：**系统启动相关文件**  
  - Linux 内核、引导程序等

- **`/dev`**：**设备文件**  
  - 把硬盘、终端等设备当“文件”来管理

- **`/etc`**：**系统和软件配置文件**  
  - 网络、用户、服务等配置

- **`/home`**：普通用户的**家目录**  
  - 如：`/home/alice`、`/home/bob`

- **`/root`**：root 管理员的家目录  
  - 注意：`/root` ≠ `/`

- **`/usr`**：**系统软件资源区**  
  - 很多应用程序、工具和共享资源

- **`/tmp`**：**临时文件目录**  
  - 程序运行时产生的临时数据，重启可能被清理

- **`/var`**：**经常变化的数据**  
  - 日志、缓存、邮件、运行数据等

- **`/sbin`**：**系统管理命令**  
  - 更多给管理员使用（管理网络、磁盘、服务等）

---

## 五、`/` 在路径中的含义

- **开头的 `/`**：表示**根目录**（绝对路径）
  - `/home/alice`：从根目录开始找

- **中间的 `/`**：表示**层级分隔符**
  - `/home/alice/test.txt`：一层一层往下

- **单独一个 `/`**：根目录本身
  - `cd /`：切换到根目录

- **Linux 用 `/`，Windows 用 `\`**
  - Linux：`/home/alice/test.txt`
  - Windows：`C:\Users\Alice\test.txt`

---

## 六、绝对路径 vs 相对路径

### 1. 绝对路径

- 从根目录 `/` 开始写的路径  
- **特点**：以 `/` 开头，路径明确

示例：

```bash
/home/alice/file.txt
```

### 2. 相对路径

- 不以 `/` 开头，从**当前目录**算起  
- 当前目录假设为 `/home/alice`：

```bash
file.txt
Documents/test.txt
```

---

## 七、本页背诵版总结

1. **Linux 只有一个顶级目录 `/`，所有文件都从这里往下展开。**  
2. **`/home` 是普通用户家目录，`/root` 是管理员家目录。**  
3. **`/etc` 放配置，`/bin` 放常用命令，`/tmp` 放临时文件，`/var` 放经常变化的数据。**  
4. **`/`：开头表示根目录，中间表示分隔符。**  
5. **命令格式：命令本体 + 选项 + 参数；本体 = 做什么，选项 = 怎么做，参数 = 对谁做。**
