Linux 入门精简笔记：`ls` 命令、HOME 目录与当前工作目录

---

## 一、`ls` 命令

### 1. `ls` 命令的作用

在命令行中，以**平铺的形式**展示**当前工作目录（默认是 HOME 目录）**下的内容（文件或文件夹）。

**一句话：`ls` 用来“看目录里有什么”。**

---

### 2. `ls` 命令的参数（目录 / 文件名）

- **作用**：可以**指定要查看的文件夹（目录）的内容**。  
- 如果**不给定参数**：就查看**当前工作目录**的内容。  

示例：

```bash
ls            # 查看当前工作目录的内容
ls /home      # 查看 /home 目录的内容
ls /etc       # 查看 /etc 目录的内容
```

---

### 3. `ls` 命令的常用选项

1. **`-a` 选项**  
   - 显示**所有内容**，包括**隐藏文件 / 目录**  
   - 以 `.` 开头的文件或文件夹默认被隐藏，需要 `-a` 才能显示出来  

2. **`-l` 选项**  
   - 以**列表（长格式）**的方式显示内容  
   - 会展示更多细节：权限、所有者、大小、时间等  

3. **`-h` 选项**  
   - 一般需要和 `-l` 搭配使用  
   - 以**更人性化的方式显示文件大小单位**（如 KB、MB、GB），更容易看懂  

---

### 4. 选项的组合使用

命令的选项可以**组合使用**，写在一起表示同时生效。

示例：

```bash
ls -lah
```

等同于：

```bash
ls -a -l -h
```

含义：以**长格式 + 人性化大小 + 显示隐藏文件**的方式，查看目录内容。

---

## 二、HOME 目录与当前工作目录

### 1. HOME 目录是什么？

- 每一个用户在 Linux 系统中都有一个**专属目录**，叫做 **HOME 目录**。  
- 默认路径：`/home/用户名`  
  - 例如：`/home/alice`、`/home/bob`

**HOME 目录可以理解为：用户在 Linux 里的“家”。**

---

### 2. 当前工作目录是什么？

- Linux 命令行在执行命令时，都有一个**当前工作目录**的概念。  
- 打开命令行程序（终端）时，**默认当前工作目录 = 用户的 HOME 目录**。  
- 很多相对路径，都是**相对于当前工作目录**来计算的。

常用命令：

```bash
pwd      # 显示当前工作目录
cd       # 不带参数，回到 HOME 目录
cd /tmp  # 把当前工作目录切换到 /tmp
```

---

## 三、本页背诵版总结

1. **`ls` 命令：用来查看目录里的内容。不给参数时，查看当前工作目录。**  
2. **HOME 目录：每个用户在 Linux 中的专属目录，默认在 `/home/用户名`。**  
3. **当前工作目录：命令执行时所在的目录，终端默认是用户的 HOME 目录。**  
4. **`ls` 常用选项：`-a` 显示隐藏文件，`-l` 列表显示细节，`-h` 人性化显示大小。**  
5. **选项可以组合使用：`ls -lah` = `ls -a -l -h`。**
